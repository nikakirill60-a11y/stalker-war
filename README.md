# S.T.A.L.K.E.R. — Tactical Zone Control

Браузерная пошаговая стратегия о контроле над Зоной отчуждения. Чистый
JavaScript + Canvas, без сборки и без внешних CDN: скачал — открыл — играешь.

![Фракции](assets/factions/monolith.png)

## Запуск

```bash
# вариант 1: просто открыть файл
open index.html            # или двойной клик по index.html

# вариант 2: локальный сервер (нужен, если браузер блокирует file://)
npm start                  # http://localhost:8080
```

Игра работает офлайн — JSZip, шрифт и все изображения лежат внутри репозитория.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | разметка меню, HUD, игрового окна |
| `css/style.css` | вся визуальная часть (CRT-эффект, панели, уведомления) |
| `js/config.js` | фракции, лидеры с бонусами, юниты, постройки, технологии, фокусы, генератор беты-карты |
| `js/items.js` | оружие, броня, ассортимент торговцев |
| `js/state.js` | состояние мира: территория, войны, союзы, юниты, артефакты |
| `js/engine.js` | игровой цикл: дни, экономика, бои, ИИ и ИИ-дипломатия |
| `js/render.js` | отрисовка карты, юнитов, аномалий и прогресса стройки |
| `js/assets.js` | манифест и предзагрузка изображений, плейсхолдеры |
| `js/mods.js` | загрузка модов из ZIP, слияние с базовыми данными, localStorage |
| `js/mod-editor.js` | редактор модов: фракции, лидеры, оружие, броня |
| `js/ui/ui-*.js` | экраны: фракция, технологии, стройка, армия, торговцы, дипломатия, моды |

## Управление

| Действие | Кнопка |
|---|---|
| Двигать камеру | `W` `A` `S` `D` |
| Зум | колесо мыши |
| Пауза | `Пробел` |
| Скорость времени | кнопки `⏸ 1x 3x 5x` в верхней панели |
| Выбрать свой отряд | правый клик по юниту |
| Приказ на движение | левый клик по клетке после выбора отряда |
| Информация о секторе | левый клик по клетке |
| Дипломатия с фракцией | правый клик по чужой клетке |
| Режим правки карты | панель справа, до входа в игру |

## Режимы

- **Бета-карта** — готовая карта Зоны (28×20, 11 фракций).
- **Своя карта** — импорт JSON вида `{"0,0": "loners", "1,0": "duty"}`.
  Неизвестные фракции отбрасываются, о проблеме сообщается в окне импорта.
- **Моды** — ZIP-архив с `mod.json` и папкой `images/`. RAR не поддерживается:
  браузерный JSZip умеет только ZIP.

## Тесты

```bash
npm install     # jsdom + sharp (нужны только для тестов и сборки ассетов)
npm test
```

- `node tests/audit.js` — статический аудит: обработчики `onclick` из разметки
  указывают на существующие методы, все `getElementById` ссылаются на реальные
  id, манифест ассетов совпадает с файлами и с данными фракций/лидеров/артефактов.
- `node tests/smoke.js` — прогон игры в jsdom за все 11 фракций: все окна,
  найм, экипировка, торговля, артефакты, дипломатия, моды и 400 игровых дней
  с проверкой инвариантов (нет дыр в карте, нет «мёртвых» юнитов, ресурсы — числа).

## Обслуживание ассетов

```bash
npm run assets
```

- `tools/prepare-assets.js` — приводит все `assets/**/*.png` к настоящему PNG
  (в исходнике они были WebP с расширением `.png`) и переименовывает
  нумерованные артефакты в смысловые ключи.
- `tools/make-icons.js` — генерирует иконки юнитов/построек и логотип из SVG,
  обрезает портреты лидеров до 165×108, оптимизирует фоны.

Проверить карту без браузера:

```bash
node tools/render-map.js /tmp/map.png
```

Скрипт поднимает игровые скрипты в песочнице, рисует настоящий canvas Зоны
через `@napi-rs/canvas` и сохраняет PNG.

## Партия и финал

Цель — взять Зону под контроль. Группировка побеждает, если удерживает
**30 % секторов** или уничтожает всех конкурентов. Проигрыш наступает, когда
у вас не остаётся территории (после одного «последнего шанса» отбить сектор)
или когда 90 дней подряд нет ни отрядов, ни схронов.

- **Экономика.** Каждый сектор приносит рубли, схрон — ещё доход и +3 к лимиту
  отрядов. Армия требует содержания; казна в минусе — отряды разбегаются.
- **Дипломатия.** У каждой пары фракций есть отношение от −100 до 100. Оно падает
  от общей границы, идеологической вражды и чужого доминирования — так войны
  случаются по причине, а не по броску кубика. Сильного лидера сдерживает коалиция.
- **Зона.** Радиация и аномалии реально снимают прочность отрядов, а артефакты
  дают постоянные бонусы: скорость, защита от радиации, урон, доход.
- **Сохранения.** Партия автосохраняется каждые 10 дней, кнопка «Продолжить»
  появляется в главном меню. Экспорт и импорт — через файл JSON.
